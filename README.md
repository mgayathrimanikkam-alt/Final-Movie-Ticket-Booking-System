# Final-Movie-Ticket-Booking-System
Console Movie Ticket Booking System using Python ,File Handling and Database Connectivity
# About
- A Console Based Movie Ticket Booking System built with Python OOP.
- It  has separate modules for Movie , User, and Booking with Data Stored Using File Handling and Database.
-  Available seats are updated automatically-they decrease when Booking and increase when Cancelled
# Features
-  Movie Module :Add new movies, Update movies ,Delete movies, Search movies, view all movies
-  User Module: Register User, Get User by E-mail
-  Booking Module : Book ticket with automatic seat reduction, Cancel ticket with seat increase ,View  Booking by User.
-  Data Storage : File Handling + SQlite3 Database Connectivity for records.
-  Tech Stack: Python ,OOP, File I/O, Database(SQLite3).
